Named areas

head holds the page heading. side contains this note. main holds the course cards. foot sits at the bottom of the layout.

Responsive course cards

This nested grid uses fractional columns and a gap. Its cards automatically reflow as the available width changes.

.grid-demo {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 20px;
}
body {
  display: grid;
  grid-template-areas:
    "head head"
    "side main"
    "foot foot";
}

.page-header { grid-area: head; }
.page-sidebar { grid-area: side; }
.page-main { grid-area: main; }
.page-footer { grid-area: foot; }

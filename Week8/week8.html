CSS Grid: Fractional Columns

Grid divides available space into columns. The fr unit shares that space proportionally, while gap adds room between cards.

Wide column · 2fr

This column gets twice the available space of either one-fraction column.

Column · 1fr

This column takes one share of the remaining space.

Column · 1fr

This column takes the same share as the other one-fraction column.

.grid-demo {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;
  gap: 20px;
}
